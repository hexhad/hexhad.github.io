The idea

A hexagon is a cell: complete on its own, and built to fit next to others. Each HEXHAD product does one job and sits beside the rest. The H inside dips at 30°, so every cut in the mark runs parallel to an edge of the hexagon.

Using the mark

  • Keep clear space equal to the width of one H stroke on every side.
  • Smallest size: 16 px with the favicon, 20 px for the outline mark.
  • One colour only: Graphite 50 on dark, Graphite 950 on light, or Cell Mint on Graphite.
  • Don't rotate, outline, add shadows to or recolour the H separately from the hexagon.

Colour and type

  • Cell Mint is the only accent. Use it for one action and one highlight per view.
  • Mint fills always carry Graphite 950 text (#04130C).
  • Geist 650 for headlines with tight tracking, Geist 400 for body, Geist Mono for code and metadata.
  • Wordmark: HEXHAD in Geist Bold, uppercase, 0.14em tracking.
